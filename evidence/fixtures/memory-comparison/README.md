# 两端记忆比较样本（T-10）

依据 PRD §9.3。全部事实均为虚构，`home/` 是两端共用的数据根样本。
`questions.json` 固定十个问题，每题列出事实来源、应答事实和应拒绝的错误结论。

先运行 `.venv/Scripts/python.exe -X utf8 scripts/verify_memory_comparison.py`，确认样本能被当前内核读取。
将 `home/` 内容复制到两端的隔离数据根，保持文件字节一致；不要覆盖日常记忆。
两端使用同一模型、参数与问题，每题开启新会话，不把上一题回答带入下一题。
Q08、Q09、Q10 要求读取笔记正文；仅看到清单摘要不算通过。

按事实含义判断 `expected`，无需逐字匹配。答案同时含有正确事实和矛盾结论也判失败。
没有记录的事实应答“未确定”或“不知道”，不得推测。输出措辞与长度不作一致性要求。
如果模型不支持笔记读取，记录为未验证，不用手动塞入正文冒充读取通过。

联调结果写入 `evidence/t10-<日期>.md`：记录两端版本、模型与参数、样本 SHA-256、
每题两端原始回答、事实是否矛盾及笔记读取记录。不得在报告中写入密钥。
当前仅验证样本和 PC 加载链路，尚无 Android 两端答案比较结果。
