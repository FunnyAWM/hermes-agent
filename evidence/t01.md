# T-01 记忆上限复验（跨端口径对齐后）

日期：2026-11-06。依据 PRD §7.2（v0.16）、TODO T-17、Android `PRD_ANDROID.md` §4.2 / 记 03。

## 契约

- `MEMORY.md`：仅模型写入受上限约束，默认 **3000**，可配置；`0` 表示不限。
- `USER.md`：**不设上限**（默认 `0`）。
- 合并上限：取消。
- 计数：码点 + 簇尾归并（组合字符、emoji 修饰符、ZWJ、国旗、标签序列算 1）。
- 超限：整次拒绝，返回实际字符数与上限，不写文件、不截断。

## 验证

```powershell
.venv\Scripts\python.exe -X utf8 scripts\verify_pc_memory_notes.py
scripts/run_tests.sh tests/tools/test_memory_contract_alignment.py tests/tools/test_memory_capacity.py tests/tools/test_memory_tool.py -q
```

结果：

- `verify_pc_memory_notes.py`：`RESULT: every check passed`；默认值 3000 / 0；2,900 字符写入后 200 字符追加被拒，文件字节不变；`USER.md` 1,400 字符写入成功并以 `unlimited` 渲染。
- 3 个测试文件：82 passed，0 failed，3 skipped（posix lane）。
- 计数用例：`e\u0301`、`👍🏽`、`👨‍👩‍👧`、`🇨🇳`、标签旗序列均计 1；`a\u0301b` 计 2。

## 边界

- 本项只验证 PC 模型写入路径；Android 侧同一契约由 `MemoryRepository` / `CharCount.kt` 负责。
- 手动编辑、历史恢复、导入不受上限约束，不在本测试覆盖范围（属 Android 端行为）。
