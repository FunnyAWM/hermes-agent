# T-02 数据根结构

## 验收结论

内核的记忆目录按 profile 的 `HERMES_HOME` 解析为 `<HERMES_HOME>/memories`，文件名分别为 `MEMORY.md` 与 `USER.md`。默认配置限制为 2,200 / 1,375 字符。`SOUL.md` 与 `AGENTS.md` 属于数据根下的上下文文件，由 system prompt 的上下文文件加载器按已有优先级读取；本项不修改该既有优先级。

## 验证

- `.venv\Scripts\python.exe -c "from hermes_cli.config_defaults import DEFAULT_CONFIG; print(DEFAULT_CONFIG['memory']['memory_char_limit'], DEFAULT_CONFIG['memory']['user_char_limit']); from tools.memory_tool_store import MemoryStore; print(MemoryStore().memory_char_limit, MemoryStore().user_char_limit)"`
- 输出：`2200 1375` 与 `2200 1375`。
- `tools/memory_tool.py:get_memory_dir()` 的实现为 `get_hermes_home() / 'memories'`，因此运行时按当前 profile 解析，不在 import 时固定路径。

## 边界

当前环境没有 pytest，且 POSIX runner 无法在 Windows 执行器直接运行；本证据覆盖默认运行时常量与路径实现，完整临时 HOME 集成回归待测试环境恢复后补跑。
