# T-03 / T-18 系统提示词顺序与根约定

状态：T-03 已完成（2026-11-03）；T-18 补根约定后于 2026-11-06 复验。

## 结论

拼装顺序为 **ROOT → SOUL → AGENTS → MEMORY → USER → NOTES INDEX → skills 索引 → 插件段 → profile → 时间 → 环境**。

- ROOT 是 `agent/system_prompt.py::MEMORY_ROOT_PROMPT`，stable 层第一段，先于 SOUL 与内置身份。
  七条约定：分层、按需读取、改前先读、`notes/docs/` 只读、保真、工具边界与 `SOUL.md`、
  自然回复。
- SOUL → AGENTS → MEMORY 连续，skills 索引不再位于 volatile 首位（T-03）。
- MEMORY / USER / NOTES 三段连续，中间不插入其它段。

## 边界

- 抓取脚本用 `sp._skills_prompt` 桩替代真实技能索引，只验证位置，不验证索引内容。
- ROOT 文本改动会使提示词前缀缓存失效；改动须随会话边界生效，不在会话中途重建。
