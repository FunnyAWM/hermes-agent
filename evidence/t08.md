产品补丁登记权威为 `PRD.md` §5.4；仓库通用约束在 `AGENTS_PROJECT.md` §4。发布 tag 的缺口另见 T-06。

| 路径 / 项目 | 类别 | 说明 |
|---|---|---|
| `config.yaml` 中的行为开关 | 配置 | 通过用户配置选择既有能力；默认值的源码改动另按受控补丁登记 |
| `plugins/`、`skills/` 的扩展 | 插件 / 技能 | 不触碰内核；现有插件 API 不提供 system-prompt 文件目录清单插入能力 |

| `agent/system_prompt.py` | 受控补丁 | T-03 把记忆顺序置于技能索引前，并为 T-04 笔记清单注入预留位置；详见 PRD §5.4 登记 |
| `hermes_notes/store.py` | 受控补丁 | T-04 独立扫描/渲染模块；清单挂钩在 `agent/system_prompt.py`，已按 PRD 登记 |
| `tools/memory_tool_store.py` | 受控补丁 | T-01 补剩余字符数提示，不改拒绝写入语义；已按 PRD 登记 |
| `hermes_cli/config_defaults.py`、`hermes_cli/source_check.py`、`hermes_cli/web_routers/actions.py` | 受控补丁 | T-11 默认关闭被动版本/插件更新；CLI 与 HTTP 被动入口经过 opt-in 门禁，保留显式检查 |
| Python / 桌面版本号 | 发布配置 | 当前 `0.22.5+fork1` / `0.22.5-fork.1`，基于冻结提交号；缺 tag 的问题另见 T-06 |
| 上游同步 | 发布流程 | `upstream` remote 未配置；稳定 release 实际升级记录依赖 T-06 / T-07，尚未完成 |

## 已核实事项

- AGENTS_PROJECT 明确本仓是 fork，产品内核补丁与基线规则例外分开登记。
- 插件 API 不是通用 prompt hook。遵循 desktop 指南“不为单一消费者造通用 extension system”的约束，notes 清单若需内核加载，应采用窄模块/窄接入点并有行为测试。
- `PRD.md` §5.4 已逐条登记系统提示词、笔记扫描、记忆超限提示及被动更新入口，文件清单与上表一致。

## 边界

本项是当前 checkout 文件归类和接口能力审阅，不代表对所有本地未提交改动来源的完整 Git 历史归因。远程 URL/分支、tag 与当前提交锚点待 T-06/T-07 证据核实。
