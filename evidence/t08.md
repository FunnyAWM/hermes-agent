# T-08 本仓定制分类

## 分类口径

以当前基座 `bf0203a794a07aac3ff764972ab9087baa4e4f4e` 为参照。产品补丁登记权威为 `PRD.md` §5.4；仓库通用约束在 `AGENTS_PROJECT.md` §4。

| 路径 / 项目 | 类别 | 说明 |
|---|---|---|
| `config.yaml`、`config_defaults.py` 中的行为开关 | 配置 | 通过用户配置改变，不更改上游逻辑 |
| `plugins/`、`skills/` 的扩展 | 插件 / 技能 | 不触碰内核；现有插件 API 不提供 system-prompt 文件目录清单插入能力 |
| `apps/desktop/` 的 renderer、Electron bridge 与打包覆盖层 | 客户端 | 桌面壳能力，不改变 agent 核心 |
| `agent/system_prompt.py` | 受控补丁 | T-03 把记忆顺序置于技能索引前，并为 T-04 笔记清单注入预留位置；详见 PRD §5.4 登记 |
| `tools/memory_tool_store.py` | 受控补丁 | T-01 修正超限提示；T-04 如需要由 notes service 接入，则扩展记忆目录数据路径；须按 PRD 登记 |
| Python / 桌面版本号 | 发布配置 | 当前 `0.22.5+fork1` / `0.22.5-fork.1`，基于冻结提交号；缺 tag 的问题另见 T-06 |
| 上游同步 | 发布流程 | `upstream` remote 未配置，T-07 需确认权限后建立稳定 release 同步流程 |

## 已核实事项

- AGENTS_PROJECT 明确本仓是 fork，产品内核补丁与基线规则例外分开登记。
- 插件 API 不是通用 prompt hook。遵循 desktop 指南“不为单一消费者造通用 extension system”的约束，notes 清单若需内核加载，应采用窄模块/窄接入点并有行为测试。
- `PRD.md` §5.4 目前已登记 system_prompt.py 和 memory_tool.py/store.py 的补丁范围。

## 边界

本项是当前 checkout 文件归类和接口能力审阅，不代表对所有本地未提交改动来源的完整 Git 历史归因。远程 URL/分支、tag 与当前提交锚点待 T-06/T-07 证据核实。
