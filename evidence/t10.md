- MEMORY 183/3000 字符、USER 80 字符（不限）；

- 新会话提示词按 MEMORY → USER → 笔记摘要拼装，笔记正文与 `DOC_BODY_MARKER` 未泄入清单；
- 根提示词锚点仍在 stable 首位；
- 十题预期事实均可在各自声明的来源中找到。

退出码 0 全对、1 缺事实或命中禁止结论、3 有题未作答（空字符串也算未作答）。用
`answers/TEMPLATE.json`（十项皆空）实跑得到 exit 3，验证缺答案分支。
