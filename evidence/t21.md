# T-21 · 单机器人 + 任务分派（2026-11-06）

目标：桌面机器人板块与手机端一致——只有一个助手、只有一段主会话、名称由用户设定；
助手能把「待办」与「定时提醒」按语义分派到正确工具。

## 实现

| 文件 | 改动 |
|---|---|
| `apps/desktop/src/plugins/hermes-bots/single-bot.ts`（新） | `singleBotRoster()` 只保留 default profile；其他 profile 继续运行，只是不在此板块列出 |
| `apps/desktop/src/plugins/hermes-bots/roster-pane.tsx` | 排序后收敛为单行；`singleBot: true` 关闭分组/隐藏段；群聊工作区与群聊列表不再渲染 |
| `apps/desktop/src/plugins/hermes-bots/roster-pane-derivation.ts` | `singleBot` 输入：隐藏行与群聊名一律为空，唯一一行不受旧 `hidden` 元数据影响 |
| `apps/desktop/src/plugins/hermes-bots/roster-pane-toolbar.tsx` | 单机器人模式只保留标题，去掉新建机器人/群聊/分组、搜索、筛选与通知开关 |
| `apps/desktop/src/plugins/hermes-bots/bot-row.tsx` | 行菜单只保留「打开对话」与「编辑资料」（名称/头像）；去掉新会话、最近会话、复制、分组、置顶、隐藏、删除 |
| `agent/prompt_builder.py` | 新增 `TASK_ROUTING_GUIDANCE`：记录/跟踪/指派 → `todo_list`；指定时间/周期/提醒 → `cronjob_manage` |
| `agent/system_prompt.py` | 仅当 `todo_list` 与 `cronjob_manage` 都在 `valid_tool_names` 时注入该段 |

`delegate_task` 本就在 `_HERMES_CORE_TOOLS`（`toolsets.py:24`），默认工具集同时启用了
`todo`、`cronjob`、`delegation`，无需新增 UI 或开关。

## 行为

- 机器人板块只有 default 一行；点击进入唯一的主会话（canonical Bot Chat）。
- 名称在「编辑资料」里设定，沿用 profile 的 title/display_name，聊天页与 About 读同一个值。
- 「把这件事记下来 / 跟踪 / 指派」→ 会话任务列表（桌面任务面板，`todo_list`）。
- 「明天 9 点提醒 / 每周五 / 定时」→ 定时任务（Routines / `cronjob_manage`）。
- 任务列表是**会话级**的：压缩后恢复、跨会话不保留；定时任务跨会话持久。路由提示不改变这个事实。

## 边界

- 桌面**全局**会话侧栏、/new、侧聊入口不在本次改动内；本条只约束机器人板块。手机端的「单一会话」
  在桌面板块内成立，桌面作为完整客户端仍保留多会话能力。
- 未在真实 Electron 窗口里点验新菜单（改的是插件组件，由 jsdom 用例覆盖）；安装包未重建。
- `todo_list` 的会话级语义来自 Hermes 内置任务面板；若要求跨重启持久的用户待办，需要另立存储，
  不在本条范围。
- 上游 `hermes-bots` 升级时，本机的收敛层（`single-bot.ts` 与四处门控）需要按行 rebase。
