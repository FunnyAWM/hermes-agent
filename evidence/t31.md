## 回归修复：快捷切换不生效/不刷新（2026-11-13）

现象：输入框左侧档位下拉选中后，命令仍用旧档位；界面也不显示切换后的值。

定位（两处）：
1. `useChatBarState` 用读取 hook 的 `writeScope`（`{connectionId, profile}` 对象）去建缓存写回器。
   `hermesConfigKey(object)` 会键成 `local::default`，而 `useHermesConfigRecord()` 读的是
   `local` —— 写回落到另一条 query 缓存行，选择器永远画旧值。
2. 配置读写都走 app 全局 profile；而沙箱门禁按**会话所属 profile** 读 `config.yaml`。
   会话 tile 固定在别的 profile 时，保存落到了另一个 home，命令自然不变。

解决：
- 缓存写回与读取使用同一个 scope 参数（字符串或 `undefined`），不再传读来源对象。
- `configProfile = modelOptionsProfile !== activeGatewayProfile ? modelOptionsProfile : undefined`：
  同 profile 的普通 tile 走共享缓存行（与设置页一致），跨 profile tile 才显式 pin；
  `saveHermesConfig(patch, configProfile)` 跟着同一 scope 走。

验证：`vitest run src/app/chat/use-chat-bar-state.test.tsx`（3 例：无 pin / 同 profile 归一 /
跨 profile pin，含“读写 scope 必须相同”断言）+ `tsc --noEmit` 0 错误。
未验证：远程网关跨 profile tile 的真实网络写入（本机只有本地 gateway）。
