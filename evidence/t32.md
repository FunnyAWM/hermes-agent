# T-32 删除会话后仍显示：会话列表缓存失效与刷新审计

日期：2026-11-13
来源：用户报告「删除会话后仍然会在会话列表里显示」，要求同时检查同类缓存未失效 / 刷新未应用问题。

## 现象

删除会话后，`/resume` 会话选择器（以及命令面板 ⌘K 的会话组）仍列出该会话；
点选它会恢复一个已被删除的 id。

## 定位

侧边栏主列表走 `$sessions` nanostore，删除路径有完整的墓碑（tombstone）与
refresh 竞态保护（`dropTombstoned` / `dropRemovalRaced`），已有 42 个测试覆盖。
漏的是**另一类读取面**——React Query 缓存的会话页：

1. `components/session-picker.tsx`：`queryKey: ['session-picker', 'sessions']`，
   沿用全局 `staleTime: 60_000`，且没有任何失效点与墓碑过滤。删除后重新打开
   `/resume`，60 秒内直接命中缓存、**不重新请求**，删除的行照常显示。
2. `app/command-palette/index.tsx`：`['command-palette', 'sessions']` /
   `['command-palette', 'archived']` 虽有 `staleTime: 0` 与墓碑过滤，但只按
   `session.id` 精确匹配；压缩后的行以 lineage tip/root 出现时不匹配。
3. `app/session-import/index.tsx` 失效 `['sessions']` —— 该 key 与上面两个
   真实 key **都不匹配**，导入后缓存从未失效。
4. `app/settings/sessions-settings.tsx` 永久删除绕过 `removeSession`：只改本页
   `useState`，不逐出 `$sessions` / `$archivedSessions`、不打墓碑、不广播；
   侧边栏「已归档」视图与其它窗口会保留该行。恢复（unarchive）同样未清
   `$archivedSessions`。
5. `removeSession` / `archiveSession` / `unarchiveSession` 成功后不广播到其它
   窗口（创建路径有 `broadcastSessionsChanged()`，删除路径没有）。

## 修复

- `store/session-removal.ts`：新增 `dropTombstonedSessions()`（按
  `tombstoneRowIds` 任一 id 匹配，无变化时保持数组引用）；侧边栏的
  `dropTombstoned` 改为调用它，墓碑集合仍由调用方传入（保留测试对
  `$removedSessionIds` 的 mock 缝隙）。
- `lib/query-client.ts`：新增 `SESSION_LIST_QUERY_ROOT = ['sessions']` 与
  `invalidateSessionListQueries()`。
- `components/session-picker.tsx`：key 改为
  `['sessions', 'picker', <connectionId>]`；`staleTime: 0`（每次打开都重新
  校验，缓存页仍即时上屏）；按 lineage 墓碑过滤。
- `app/command-palette/index.tsx`：key 归到 `['sessions', 'palette' | 'palette-archived',
  <connectionId>]`；会话与归档两组都用 `dropTombstonedSessions`。
- `app/session-import/index.tsx`：改用 `invalidateSessionListQueries()`，失效
  真正存在的缓存键。
- `use-session-actions`：删除 / 归档 / 恢复成功后 `invalidateSessionListQueries()`
  + `broadcastSessionsChanged()`。
- `settings/sessions-settings.tsx`：永久删除先打墓碑 + `beginSessionMutation`，
  成功后 `dropListedSession`、清 `$archivedSessions`、失效查询并广播；
  失败回滚墓碑。恢复时同步清 `$archivedSessions`；跨窗口 `onSessionsChanged`
  静默重载本页（不闪骨架屏）。
- `use-desktop-integrations.ts`：跨窗口广播监听同时失效会话页缓存。
