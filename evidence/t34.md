# T-34 · 输入框档位下拉新增 Auto Review 开关

日期：2026-11-13

## 需求

用户：Auto Review 也应作为一个可切换的档位存在，切换到时使用 Auto Review。
裁决（AskUserQuestion）：落在**输入框沙箱档位下拉**；与沙箱档位**独立并存**，退出时恢复
切换前的审批模式。

## 实现

- `apps/desktop/src/app/chat/composer/types.ts`：`ChatBarState['sandbox']` 增
  `approvalMode: ApprovalMode` 与 `onToggleAutoReview(enabled)`。
- `apps/desktop/src/app/chat/use-chat-bar-state.ts`
  - 读 `$approvalModes`（按 `modelOptionsProfile || activeGatewayProfile` 作用域，
    空名归一为 `default`），未同步时沿用既有 `smart` 默认。
  - 写入走 `setApprovalModeForProfile(requestGatewayForActiveRoute(profile, …))`：
    与状态栏审批芯片同一条网关路由，保证云端/远程 profile 落到正确的家目录；
    失败由 store 回滚到已确认模式。
  - 打开前把当前模式记进 `previousApprovalModes` ref（按 profile 分键）；
    关闭时恢复它，缺失则回 `smart`。沙箱 profile 完全不动。
- `apps/desktop/src/app/chat/composer/sandbox-pill.tsx`：菜单顶部加
  `DropdownMenuCheckboxItem`（Auto Review + 一句说明），`onSelect` 阻止默认关闭，
  勾选后仍可继续挑沙箱档位；失败用 `autoReviewSaveFailed` 提示。
- i18n：`composer.autoReview / autoReviewDescription / autoReviewSaveFailed`
  进 `types.ts` 与 9 个语言文件（en/de/es/fr/ja/ru/zh/zh-hant/ar），
  `locales/_keys.desktop.json` 已重新生成。
