# T-35 · 审批对话框展示命令与 justification，并提供用户语言的理由

日期：2026-11-13

## 需求

用户：审批对话框本身应当包含要执行的命令和 justification，供用户辨别是否要执行；
justification 应当使用用户使用的语言，引导模型这样生成 justification。

即两件事：

1. Auto Review 判 deny / 失败转人工时，人工看到的不只是「原因一句话」，还要看到
   即将执行的具体调用（命令 / 参数摘要）。
2. 那句理由（justification）由审查模型写，但必须是用户的语言，并直接对用户说。

## 实现

### 审查侧：理由成为一等字段

- `tools/auto_review.py`
  - `REVIEW_POLICY` 追加约束：`reason` 会原样展示在待执行操作旁，因此必须用
    `<history>` 中最近一条 USER 消息的语言书写（没有用户文本时用英文）、直接对用户说话、
    一句话且点名具体效果；不得提及审查器本身或声称的意图。
  - `gate_tool_call` 的 `ask()` 同时传 `command=_call_text(tool, args, ...)` 与
    `justification=reason`，人工闸门拿到「命令 + 理由」两段。
- `tools/approval.py`
  - `_run_approval_gate(..., justification="")`、`_human_decision(..., justification="")`、
    `_pending_result(..., justification="")` 一路透传；pending 队列在人工答复前重放时
    仍带理由。
  - 新增 `_redacted_justification()`：空串返回 `{}`，否则返回
    `{"justification": redact_approval_display(...)}`，出口统一走脱敏。
  - `request_tool_approval(..., command="", justification="")` 的显示目标改为
    `command or "<tool> (plugin approval rule)"`。

### 网关侧：三条出口都带理由且脱敏

- `tui_gateway/server.py`：`_approval_request_payload` 的脱敏键扩到
  `command` / `description` / `justification`。
- `gateway/session_pending_controls.py`：提示里附加脱敏后的 `justification`。
- `gateway/session_ancillary.py`：待审批列表带上 `justification`。
- `gateway/session_managed_worker.py`：审批帧白名单加入 `justification`。
- `gateway/platforms/api_server.py`：`_approval_request_event` 同样对三键脱敏。

### 桌面侧：卡片显示命令与理由

- `apps/desktop/src/store/prompts.ts`：`ApprovalRequest.justification?: string`，
  `PendingApprovalPayload.justification?: unknown`，重放映射同步。
- `apps/desktop/src/app/session/hooks/use-message-stream/gateway-event/server-requests.ts`：
  审批事件映射 `justification`。
- `apps/desktop/src/components/assistant-ui/tool/approval.tsx`：新增
  `ApprovalJustification({ label, text })`，空串不渲染，`data-slot="tool-approval-justification"`，
  排在命令 `<pre>` 之后——先看要执行什么，再看为什么。
- i18n：`assistant.approval.justification` 进 `types.ts` 与 9 个语言文件
  （en Justification / de Begründung / es Justificación / fr Justification / ja 理由 /
  ru Обоснование / zh 理由 / zh-hant 理由 / ar المبرر），`locales/_keys.desktop.json`
  已重新生成。

## 未验证

- 真机 Electron 点击走查（本环境无 GUI）：未在打包应用里截图确认命令块与理由块的
  视觉顺序与长文本换行。
- 非英文场景下审查模型的实际输出语言质量：提示已约束，但辅助模型是否稳定遵循
  「最近一条 USER 消息的语言」需真实模型采样；当前只用桩响应覆盖了提示内容与
  透传链路。
- `reason` 脱敏后可能变短（`redact_approval_display` 会改写疑似路径/密钥片段），
  长命令的展示截断阈值沿用既有限制，未逐语言校核长度。
