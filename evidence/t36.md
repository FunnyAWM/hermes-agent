## 新版本不兼容项与修正

1. **npm → pnpm**：上游 v0.23.2 用 pnpm 接管 JS 工作区，`pm/lock.json` 钉 `pnpm 12.15.0`，`lefthook.yml`
   改为 `just` → `pnpm exec eslint`。修正：`build.ps1` 改 `pnpm run build` / `pnpm exec electron-builder`；
   `scripts/download-managed-tools.ps1` 注释与 `electron-builder.fork.cjs` 注释改 pnpm；`INSTALL.md`
   前置工具表把 `npm 12.0.2` 换成 `pnpm 12.15.0`，`pm install` 示例同步。
2. **版本号**：基座变更后两处 `version` 必须重写（`AGENTS_PROJECT.md` §2）。改为
   `pyproject.toml = 0.23.2+fork1`、`apps/desktop/package.json = 0.23.2-fork.1`；§2 基座行记录 v0.23.2
   （本地无该 tag，保留“待 `git ls-remote --tags` 核对”的既有说明）。
3. **`agent/tool_executor.py` 越过 2 000 行棘轮**：合并后 2 007 行（上游 1 981）。把 Auto Review
   闸门移入新 sibling `agent/tool_executor_auto_review.py`（`auto_review_block`），facade 内延迟导入，
   回到 1 998 行。
4. **`AGENTS.md` 链路 30 000 字符上限**：合并后 `AGENTS.md + tools/AGENTS.md` = 30 361。压缩 fork
   自有的结构树说明、`sync` 路由行与 `Working constraints` 文案，并精简 `tools/AGENTS.md` 的沙箱说明，
   回到上限内（`scripts/ci/check_agents_md_size.py` exit 0）。
5. **`scripts/ci/prompt_surface.py` 在 Windows 无法解析 home**：渲染子进程只设 `HOME`，而 Windows 的
   `pathlib` 读 `USERPROFILE`，报 `Could not determine home directory`。补
   `env["USERPROFILE"] = str(home)`（仍指向临时 home，不泄漏调用方配置）。
6. **合并遗留缩进**：`tools/approval.py` 的参数续行、`tools/file_operations_search.py` 的注释缩进、
   `pm/install.py` 的 `known.append` 对齐，均在适配提交里修正。
