## 交付内容

- `agent/session_window.py`：窗口排程纯函数（`window_settings` / `user_turn_count` /
  `kept_turn_count` / `request_start_index`）。`context.session_window_turns` = X 只把最近 X 轮
  用户消息发给模型；`context.frozen_window_turns` = Y（须 `1 <= Y < X`）在满 X 轮时把最近 Y 轮
  冻成请求前缀，之后每轮追加一条直至 total == X+(X−Y) 再重冻——冻结前缀稳定，保住提示词缓存。
- `agent/agent_init.py` 读两个配置键；`agent/turn_context.py::build_api_messages` 在
  `canonicalize_replay_history` 之后对**发送副本**裁剪，落盘历史、界面与压缩摘要不变，
  压缩预估按裁剪后内容计；裁剪不越过本轮用户消息。
- `hermes_cli/web_server_config.py`：两键为 schema 虚拟字段（默认 0 关闭），不进 `DEFAULT_CONFIG`
  （FILE_LINES 棘轮）。
- Desktop 设置 → 对话 → 机器人：`config-subpages.ts` 的 `bot` 页挂两字段；
  `constants.ts` fieldLabels/fieldDescriptions；de/es/fr/ja/ru/zh-hant 文案同步，
  `overlay-gaps.json` 只余 ar 的已知缺口。
- `apps/desktop/src/app/settings/subpages.ts`：`settings=...` 深链在无 manifest 行时按完整
  配置键路由到所属子页（否则 `setting=context.session_window_turns` 落回首个子页）。
