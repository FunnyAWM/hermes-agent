# T-39 · pm 下载包走镜像站（`HERMES_PM_DOWNLOAD_MIRROR` 前缀重写）

日期：2026-11-17

## 交付内容

- `pm/artifact_mirror.py`：新增 `HERMES_PM_DOWNLOAD_MIRROR`（ghproxy 式
  `<prefix><original URL>`）。`pinned_source` 在前缀未设时行为不变；设了则镜像优先、
  原站与 hermes-assets 公共归档兜底，sha256 全程校验；http 前缀沿用 LAN npm registry
  信任模型（#150032：用户配置 + 钉死哈希 + 限长）；非法值抛 `InstallError`。
- `tests/pm/test_artifact_mirror.py`：5 个新用例——前缀重写与兜底链、前缀压过 npm
  registry、http 前缀的 `http_mirror`、非法值 fail-closed、range-server 端到端。
- 文档：`website/docs/reference/package-management.md` § Release age and package mirrors
  补 knob 说明（`Every other download stays HTTPS-only` 随之修订）；PRD §5.4 补丁表一行 +
  变更记录 v0.28。

## 背景

npm/PyPI 原本就有镜像 knob（`npm_config_registry` / pip.conf `index-url`）；
`pm/lock.json` 里 104 个 GitHub URL 等其余下载源没有，只能回退同样不可达的
hermes-assets。全部受管工具下载走 `store.fetch_many` → `pinned_source` 单一漏斗，
在此加前缀重写即覆盖全部包。
